# Projeto de Codificação Huffman

## Descrição
Implementação do algoritmo de compressão de Huffman em C, incluindo:
- Árvore de Huffman
- Fila de prioridade (min-heap)
- Funções para manipulação da árvore e fila

## Estrutura do Projeto
projeto_huffman/

├── huffman_heap.h # Header com as declarações

├── huffman_heap.c # Implementação do TAD

├── main.c # Programa de teste

└── README.md # Documentação

## Como Compilar

gcc -Wall -g main.c huffman_heap.c -o huffman

./huffman
